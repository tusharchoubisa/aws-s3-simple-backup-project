# AWS S3 Simple File Backup Project

## Project Overview

This project demonstrates basic cloud storage and file backup operations using Amazon Web Services (AWS) S3.

The main objective is to upload files to an S3 bucket, organize them into folders, and maintain a separate backup copy.

## Tools and Technologies

- Amazon Web Services (AWS)
- Amazon S3
- AWS Management Console

## Project Tasks

1. Created an S3 bucket.
2. Uploaded a file to the S3 bucket.
3. Created a `backup` folder.
4. Uploaded a separate copy of the file into the backup folder.
5. Verified that the backup file was successfully stored.
